# MP整理纠正

检查 MoviePilot 成功整理记录中使用英文标题命名的媒体，优先按源文件中的中文片名搜索；没有中文时回退英文片名。年份可选，并支持人工模糊搜索和安全重新整理。

## 安全规则

- 插件没有删除源文件的接口，`move` 记录会强制改用 `copy`。
- 重新整理前必须预览新路径。
- 新媒体整理成功、记录匹配且目标存在后，才允许删除旧英文媒体。
- 重新整理失败时恢复原整理记录，旧媒体保持不动。
- 模糊、同名、年份不一致和电视剧记录只能人工确认。
- 手动批量纠正不限制数量；“一键全部纠正”会跨分页处理全部唯一精确匹配电影。

## 定时任务

默认每天 04:00 增量扫描。自动纠正默认关闭；开启后也只处理中文片名、年份和类型唯一精确匹配的电影，并受单次数量限制。
